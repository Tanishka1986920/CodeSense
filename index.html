          Help & Legend

          Quick guide to using CodeSense, understanding scores, and reading issues.

          How to use

          • Login required: Login or sign up before running analysis. New users should sign up once, then login.
          • Analyze: Paste code or upload/drop a file, choose language (or Auto-detect), then click Analyze Code (Ctrl+Enter).
          • History: Analyses are saved to your profile (server mode) so you can reopen them later.

          Severity legend

          • error Likely bug, risky pattern, or issue that should be fixed.
          • warning Code smell or potential problem worth reviewing.
          • info Suggestion or improvement opportunity.

          Scores & metrics

          • Health score (0–100): Overall code quality signal based on detected issues and complexity.
          • Maintainability: Readability/maintainability index derived from complexity and code quality signals.
          • Cyclomatic complexity: Estimate of decision-path complexity (higher usually means harder to test/maintain).
          • Nesting depth: Maximum nested block depth; deep nesting can reduce readability.
          • Duplication/comment metrics: Signals for repeated lines and documentation/comment coverage.

          Notes

          • Analysis is heuristic/rule-based (not a compiler or ML model), so some issues may be missed or flagged conservatively.
          • When running with node server.js, profile history is stored locally on this machine in CodeSense/data/db.json.
